    How it works, in detail

    Browser edition
    1. Prepare Excel and make a reusable PowerPoint template

    Keep the figures you report in a consistent workbook structure. For this sales example, the sheet is named Summary: B1 contains the reporting date, B2 the revenue, B3 the growth rate, and B4 the top region.

    Make a copy of your existing PowerPoint deck. In that copy, replace each changing figure with a token that points to the corresponding cell. You only do this setup once; keep this marked-up copy as your template.

    Inside your templateRevenue reached {{Summary!B2|$#,##0}}
    Growth: {{Summary!B3|0.0%}}
    Reporting period: {{Summary!B1|date:mmm yyyy}}    After refreshing with September dataRevenue reached $1,347,905
    Growth: 4.9%
    Reporting period: Sep 2026

    The part before | identifies the cell. The part after it formats the result. You can also reference an Excel named range, such as {{TotalRevenue}}. Tokens split across text formatting runs still resolve; the replacement inherits the first character's formatting.

    2. Connect tables, charts, and pictures

    For these objects, use a shape name instead of typing a token. Open PowerPoint → Home → Select → Selection Pane, select the object, and rename it with the directive below.

    table:Regions!A1:D5
    Use an existing PowerPoint table. The range fills the table and resizes its rows and columns while inheriting the template's cell styling.
    chart:Regions!A1:D5
    Use an existing chart. The first column supplies categories and the header row supplies series names. Add ;orient=rows to switch orientation. The displayed chart cache updates; the embedded worksheet behind PowerPoint's “Edit Data” keeps its original values.
    picture:Regions!A1:D5
    Use an existing picture as the placeholder. The browser renders the range as a neutral table image and replaces the picture in the same position, size, and layer order. The Excel add-in edition provides a pixel-perfect Excel picture.
    3. Load files and refresh the deck
    1. Save your workbook in Excel after changing formulas. The browser reads saved, cached results; it does not recalculate formulas.
    2. Add the workbook to the source area. Add one or more marked-up .pptx files to the template area.
    3. Optionally add an approved log CSV from a previous run to compare against that baseline.
    4. Refresh. Tokens, tables, charts, and pictures resolve against their named sheets or ranges. Your original template remains unchanged.

    For batch output names, your workbook can include a Decks sheet with Template, Output, and Skip columns. Tokens on a slide layout or master resolve once and appear on slides that inherit them.

    4. Understand the preview, change log, and feedback

    The slide preview shows how the figures land in the template's shape geometry. Each action is logged with its source reference so you can trace what changed.

    Read-back verification
    The generated PowerPoint file is reopened from its own bytes. Text values, table dimensions, chart series and point counts, picture replacements, and unresolved references are checked against the log.
    Baseline comparison
    With an approved log, moved values are tagged CHANGED. A reference that stopped resolving or a renamed shape can produce MISSING or MISMATCH findings. Download findings as deck-updater-qc.csv.
    Unresolved references
    They stay visible in red in the preview and remain unresolved in the deck. An error does not abort the entire run; a deck can still be saved with issues. Review the findings before sending it.
    5. Download and reuse next period

    Download the updated PowerPoint deck after checking the results. Keep the original template for the next reporting period; swap in the next workbook and repeat.

    PDF export is a read-only circulation copy. It uses the preview, which simplifies template fonts, theme colors, and effects. Updated charts appear as signed bar charts regardless of their original chart type; charts without directives appear as labeled outlines. For exact styling, open the finished deck in PowerPoint.

    Worked example: trace the investment-view deck

    Your GitHub example pairs Lynch_Buffett_Stock_Evaluation.xlsx with Investment_View_Template.pptx. Forty-two values feed six slides:

    1. Recommendation, price, fair value, upside, and buy-below price.
    2. A decision summary table and a valuation-bridge chart.
    3. A chart of six score modules.
    4. Forecast rows and a five-year revenue chart.
    5. Eleven data-quality checks with details.
    6. Assumptions against history and the metrics behind the score.

    For example, {{03_Output_Decision!B12}} reads the recommendation, and table:03_Output_Decision!A5:B15;header=0 fills the decision table. The model's blocking flags force REVIEW and withhold unsupported fair-value outputs. These checks come from the workbook; Deck Updater transfers their results.

    How it works

    The idea is to stop rebuilding the same deck. Mark up the one you already remake every month, once. After that it is a template, and a new period costs you a workbook and a few seconds.

    1

    Mark it once

    Open the deck you rebuild every period. Replace each figure with the cell it comes from. That copy is now your template; keep it and never edit it again.

    2

    Reuse it each period

    Drop the template with this period's workbook. Every marked figure, table and chart refills. The template itself is never touched.

    3

    Check, then send

    Each change is listed with the cell it came from, and the saved file is read back to confirm it really says that.

    Your template (written once)

    Reporting period: {{Summary!B1|date:MMM yyyy}}
    Revenue reached {{TotalRevenue|$#,##0}} ({{Summary!B3|0.0%}} vs last year)
    Top region: {{Summary!B4}}

    →
    Output · july.xlsxaugust.xlsxseptember.xlsx

    Reporting period: Jul 2026Aug 2026Sep 2026
    Revenue reached $1,102,400$1,284,530$1,347,905 (4.1%8.3%4.9% vs last year)
    Top region: SouthNorthNorth

    The template never changes. Each period brings a new workbook, and the format after the | is yours: month and year, a full date, whatever the slide needs.

    What you can mark

    To updateDo this
    A number or word in textType {{Sheet!B2}} on the slide
    A tableName the table table:Sheet!A1:D5
    A chartName the chart chart:Sheet!A1:D5
    A picture of a rangeName the picture picture:Sheet!A1:D5

    Shapes are renamed in PowerPoint under Home → Select → Selection Pane.

    More options

    Formatting a value

    {{Summary!B3|0.0%}}Your own number format. #,##0, $#,##0.00 and #,##0;(#,##0) all work.
    {{Summary!B1|date:MMM yyyy}}A date in the pattern you choose.
    {{TotalRevenue}}A named range; survives rows being inserted above.
    'Q3 Data'!A1:D12Quotes are needed only when the sheet name has spaces.

    Footers and dates on every slide

    Mark the slide layout or the slide master instead of a slide, and the value is written once but appears on every slide that uses it: a reporting date, a data-as-of stamp, a classification line.

    A whole reporting pack

    Drop every template in the pack and each gets its own tab. To name the outputs from the workbook, add a sheet called Decks or Setup:

    TemplateOutputSkip
    board-pack.pptxBoard pack Aug 2026.pptx
    regional.pptxRegion review.pptxY

    Drop a second workbook to pull from both: prefix with its file name, as {{budget:Summary!B2}}.

    Checking the run

    Every run is read back: the finished .pptx is re-opened and each logged value checked against what the file actually says. Drop a log you have signed off into the third box to also compare runs: a value that moved shows as CHANGED, a token that stopped resolving or a shape that was renamed as MISSING or MISMATCH.

    If something doesn't update

    Token still showsThe reference didn't resolve; the panel names the sheet it couldn't find.
    Table or chart unchangedThe directive goes in the shape name, not the text on it.
    Old numbersSave the workbook in Excel first; cached results are read, not recalculated.
